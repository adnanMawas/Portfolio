# Adnan Mawass — Developer portfolio

A responsive static portfolio featuring ShopOS, Tap and Go, and Premier League Predictions.

Open `index.html` in a browser or serve the repository root with any static web server:

```sh
python3 -m http.server 8000
```

The page can be hosted directly from the root of the `main` branch with GitHub Pages. There is no build step.

Adapted from [Simplefolio](https://github.com/cobidev/simplefolio) by Jacobo Martínez. The original template is MIT licensed. See [LICENSE](LICENSE).
